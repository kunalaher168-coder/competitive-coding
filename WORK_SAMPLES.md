# Work samples and public scope

This portfolio presents general algorithm skills through newly written public examples. It is not a submission archive.

## Algorithm design

**Graph reasoning.** Built and reviewed weighted-graph tasks involving state transitions, route costs, and unreachable targets. The public travel-pass example demonstrates explicit state modeling and a priority queue.

**Trees and data structures.** Worked on tree traversal, aggregate queries, and dynamic-programming cases. The public tree example shows a two-pass rerooting derivation with linear work.

**Arrays and optimization.** Worked on two-pointer, sliding-window, and prefix-aggregate cases. The public window example focuses on maintaining a valid invariant as the range expands and contracts.

**Simulation and dependency rules.** Worked on deterministic simulation and ordering problems, including conflict cases. The public scheduler and dependency planner show event ordering, tie handling, and cycle reporting.

**Interactive reasoning.** Worked on query strategies and bitmask-style state representations. No private interaction protocols or judge materials are included.

## Evidence boundary

Public code establishes technical capability. Private source folders can support a confidential review only where sharing is authorized. This repository contains no copied prompt, reference solution, test corpus, guideline, organization name, client name, or record identifier.
